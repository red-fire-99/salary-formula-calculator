## 这个计算器能算什么？

| 你想知道 | 对应指标 | 常用系数 |
| --- | --- | --- |
| 每个月该存多少钱 | 月度储蓄 / 投资 | 月薪 × **20%** |
| 失业时能撑几个月 | 应急备用金 | 月薪 × **3**（或 3–6 个月开销） |
| 每月最多花多少 | 支出上限（红线） | 月薪 × **50%** |
| 多少钱可以躺平 | 财务自由目标 | 月薪 × **300**（4% 安全提取率） |
| 重疾/失业的保障缺口 | 失能保障金 | 月薪 × **12** × **5** |

> 也就是常见的 **50/30/20 法则**（必要支出 / 想要的消费 / 储蓄投资），外加两个更实用的长线目标。
> 关于「×300」：目标金额 × 4% ÷ 12 ≈ 当前月工资，即每月被动收入能覆盖今天的薪资水平。

## 一、项目简介

很多人知道「要存钱、要留备用金」，但不知道具体该存多少、花多少、攒到多少才能不焦虑。本项目把五条流传最广的**经验法则**做成一个实时计算器：填一次月工资，就把储蓄额、备用金、支出红线、财务自由目标、失能保障缺口一次性摆在你面前。

它刻意做得极简——**没有账号、没有后端、没有统计、没有网络请求**。所有计算发生在你的浏览器里，关掉页面数据就消失。适合作为个人财务自检工具，也适合作为「纯前端无依赖小工具」的参考实现。

## 三、五个公式

| # | 指标 | 公式 | 它解决什么问题 |
| --- | --- | --- | --- |
| 1 | 月度储蓄 / 投资金额 | 月工资 × 0.2 | 发薪后优先划走的 20%，用于定投与长期积累，建议设置自动转账 |
| 2 | 基础生活备用金 | 月工资 × 3 | 覆盖约 3 个月基本开销的现金池，应对失业、突发支出 |
| 3 | 月度支出上限 | 月工资 × 0.5 | 所有消费的硬红线，守住它才能保证储蓄率不被侵蚀 |
| 4 | 财务自由目标金额 | 月工资 × 300 | 攒到该规模后投入年化约 4% 的工具，**每月被动收入 ≈ 当前月工资** |
| 5 | 失能保障备用金 | 月工资 × 12 × 5 | 重疾或意外导致长期无法工作时的收入缺口，建议用保险保额覆盖 |

> 关于第 4 项：目标金额 × 4% ÷ 12 = 月工资。页面会在卡片副标题里实时算出这个被动收入数字，方便你直接核对。

## 四、安装与运行

**依赖声明：本项目没有任何运行时依赖，也没有构建步骤**，因此不引入 `package.json` / `requirements.txt`，避免为了「看起来规范」而增加无意义的依赖树。

三种方式任选其一：

### 方式 1：直接打开（最简单）

下载或克隆仓库后，双击 `index.html`，用浏览器打开即可，无需任何安装。

### 方式 2：本地静态服务器（推荐，便于调试）

```bash
# Python 3
python -m http.server 8000

# Node.js（无需安装依赖）
npx serve .

# 然后访问：http://localhost:8000
```

### 方式 3：部署到线上

因为它是纯静态文件，可直接托管到任意静态平台：

- **GitHub Pages**：仓库 Settings → Pages → Source 选 `main` 分支根目录
- **Vercel / Netlify**：导入仓库，构建命令留空，输出目录填 `.`
- **对象存储 / Nginx**：把 `index.html` 传到任意静态目录即可

## 六、项目结构

```
.
├── index.html        # 全部内容：HTML + CSS + 原生 JS，单文件即完整应用
├── .gitignore        # 屏蔽工作区数据、密钥、依赖、系统与编辑器文件
├── .env.example      # 环境变量示例（本项目运行时无需任何密钥）
├── LICENSE           # MIT 许可证
└── README.md         # 本文件
```

**为什么是单文件？** 这个工具的全部逻辑不到 400 行，拆分成 `css/`、`js/`、`assets/` 只会增加加载请求和维护成本。单文件可以直接双击打开、可以直接发给同事、可以离线存进网盘——这是它的核心价值。若未来需要多页面或引入构建，再拆分也不迟。

## 七、浏览器支持

Chrome / Edge / Firefox / Safari 的近两年版本，以及对应的移动端浏览器。使用了 CSS 变量、CSS Grid、`toLocaleString` 与 ES5 级 JavaScript，不依赖任何新语法特性。

## 八、隐私与安全

- **不联网**：不含任何 `fetch` / `XHR` / `WebSocket` / 外部脚本或字体请求，断网可用。
- **不存储**：不使用 Cookie、`localStorage`、`sessionStorage`，刷新即清空，不留痕。
- **不采集**：无统计脚本、无埋点、无账号体系。
- **不上传**：你输入的工资数字只在当前页面的内存中参与计算，不会离开你的设备。
- **无密钥**：代码与配置中不存在 API Key、Token、密码、私钥或数据库连接串；若你二次开发时引入服务端，请把密钥放进环境变量（参考 `.env.example`），切勿写进仓库。
